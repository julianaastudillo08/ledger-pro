# Ledger Pro

**English:** Personal finance ledger in Colombian pesos (COP). Track income and expenses by category, view a monthly chart, and export CSV. Runs entirely in the browser.

**Español:** Contabilidad personal en pesos colombianos: ingresos, gastos, categorías, gráfico mensual y exportación CSV. Sin servidor.

## Demo

https://julianaastudillo08.github.io/ledger-pro/

## Local use

Open `index.html` or serve this directory statically.

## Stack

HTML, CSS, JavaScript, [Chart.js](https://www.chartjs.org/) (CDN).
