# Ledger Pro

**English:** Personal finance ledger in Colombian pesos (COP): month navigation, budget goals per category, monthly comparison bars, recurring transactions, balance sparkline & Chart.js trends, balance forecast, CSV import/export, print/PDF stylesheet, and dark/light theme. Runs entirely in the browser.

**Español:** Contabilidad personal en COP: navegación por mes, metas por categoría, barras comparativas, transacciones recurrentes, tendencias, proyección de balance, importar/exportar CSV, estilos de impresión y tema claro/oscuro.

## Features / Características

- Month-focused stats with sparkline and category chart / Estadísticas y gráficos
- Budget progress bars per expense category / Metas de presupuesto
- Recurring monthly rules auto-applied / Recurrencia mensual
- CSV import & export / Importación y exportación CSV
- Dark/light toggle (charcoal & deep green aesthetic) / Tema dual
- Print-friendly report layout / Vista imprimible
